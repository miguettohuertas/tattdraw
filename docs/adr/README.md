# Registros de decisão de arquitetura (ADRs)

Um ADR é um texto curto que registra **uma** decisão importante: o contexto, o que foi decidido e as
consequências. Servem para você (ou alguém no futuro) entender _por que_ o projeto é como é.

Como criar um novo:

1. Copie o último arquivo e aumente o número (`0004-...md`).
2. Preencha **Contexto**, **Decisão** e **Consequências**.
3. Uma decisão não é apagada: se mudar, crie um ADR novo e marque o antigo como "Substituído por 000X".
