# 0001 — Registrar decisões de arquitetura

- **Situação:** Aceita
- **Data:** 2026-11-02

## Contexto

O projeto é desenvolvido por uma pessoa, que quer entender cada passo. Decisões tomadas hoje
(stack, formato de arquivo, modelo do corpo) vão ser questionadas daqui a meses.

## Decisão

Toda decisão que for difícil de desfazer vira um ADR em `docs/adr/`, numerado em ordem.

## Consequências

- Fica claro por que cada escolha foi feita e o que se sabia na época.
- Custa alguns minutos por decisão.
